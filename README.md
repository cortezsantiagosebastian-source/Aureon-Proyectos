# Aureon-Proyectos

Repositorio de contexto, research y entregables para los proyectos y alianzas externas de Aureon Estudio (fuera del sitio web principal).

## Estructura

- **proyecto-mauricio/** — Alianza Web3 / Trazabilidad Blockchain con Mauricio (Uruguay). Relacion de mentoria/intercambio, no cliente que factura.
- **proyecto-rhizoma/** — Desarrollo real (sitio web + sistema de ventas) para RHIZOMA, banda de musica. Aureon aparece solo como sponsor, nunca como marca ejecutora visible.
- **proyecto-walpulse/** — Alianza Web3 / Reputacion On-Chain con Jair (WalPulse, GlobalScoreAgent, Walcert).

Cada carpeta tiene su propio README.md con contexto completo, estado actual y reglas especificas del proyecto.

## Nota

El codigo fuente del sitio web principal de Aureon Estudio (aureon-web) se aloja por separado en este mismo repositorio, en la carpeta `aureon-web/`, conectado a Cloudflare Pages para auto-deploy.
