# AUREON × JAIR — Alianza Web3 / Reputación On-Chain

## Qué es esto
Repositorio de contexto, research y entregables para la alianza exploratoria entre Aureon y Jair. **No es un cliente que factura** — conocido a través de la comunidad Ethereum Uruguay, ganador de ETH Uruguay.

## Quién es Jair
Founder solo de tres proyectos:

Ya tiene contactos reales de exchanges (nexchange.uy, roderichs_crypto_house.uy) — no necesita más leads, necesita que el proyecto no suene a producto de hackathon.
- **GlobalScoreAgent** — pendiente de research profundo.
- **Walcert** — pendiente de research profundo.

## Contexto técnico relevante (research propio, no inventado)
- **ERC-8004 (Trustless Agents):** estándar Ethereum, mainnet desde 29/1/2026. Define 3 registros on-chain (Identidad, Reputación, Validación). Autores incluyen Ethereum Foundation, ConsenSys, Coinbase. Existe explorer público (QuickNode ERC-8004 Explorer). Se conecta al stack de "comercio agéntico" (x402, protocolo A2A). WalPulse encaja conceptualmente como capa de señales sobre este estándar.
