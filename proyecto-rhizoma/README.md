# RHIZOMA — Sitio Web + Sistema de Ventas

## Qué es esto
Proyecto de desarrollo real (código, no solo estrategia) para RHIZOMA, banda de música — contacto vía red personal de San (recomendación de su madre). **No lleva marca Aureon visible** — Aureon aparece únicamente como sponsor en el evento en sí, nunca como ejecutor del trabajo (ver regla de posicionamiento en AUREON_MASTER_v6).

2. 2. Sistema de ventas / captación de sponsors y partners para su evento en vivo.
   3. 3. Estrategia de marketing para esas ventas.
